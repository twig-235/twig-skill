# Game character art for Grok

Read `../../spec.md` before generating. Treat it as the output contract and use `../../references/` only for visual direction. Establish the character in full art first and reuse that approved identity for chat, icon, and grid prompts.

If the environment cannot preserve alpha or reference-image identity, stop before writing final files and report the failed requirement. The completed character folder contains only `full.png`, `chat.png`, `grid.png`, and `icon.png`.
