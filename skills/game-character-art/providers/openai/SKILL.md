# Game character art for OpenAI/Codex

Read `../../spec.md` before starting and follow it as the output contract. Inspect `../../references/` for visual style and `../../prompts/` for reusable prompt scaffolds.

Use the built-in image generation or editing tool for the artwork. Generate the approved full illustration first, then use it as the identity reference for chat, icon, and grid. Use local image tools only for alpha inspection, resizing, cropping, grid assembly, and validation.

Save only `full.png`, `chat.png`, `grid.png`, and `icon.png` in the requested character folder.
